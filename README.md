# 🍽️ Restaurant Management & Ordering System

A full-featured, dynamic web application designed for restaurant management, online food ordering, and seamless administrative control. Built with PHP (Laravel) and MySQL.

---

## 🚀 Features & Architecture

### 🌐 Frontend (User & Public Interface)
* **Dynamic Menu & Categories:** Browse various food items categorized neatly (e.g., Starters, Main Course, Desserts, Drinks).
* **Online Ordering System:** Add items to the cart, manage quantities, and place orders smoothly.
* **Responsive Design:** Fully mobile-friendly and modern user interface styled with clean layouts and Blade templates.
* **User Authentication:** Customer registration, secure login, and profile management.
* **Contact & About Pages:** Informative pages for customer support, location details, and restaurant background.

### ⚙️ Backend (Admin & Management Panel)
* **Admin Dashboard:** Centralized control panel to monitor overall restaurant operations and database metrics.
* **Menu & Category Management:** Add, edit, or delete food items, update prices, and manage categories dynamically.
* **Order Tracking:** View incoming customer orders, manage order statuses, and handle processing efficiently.
* **Database Migrations & Seeders:** Structured database handling using Laravel migrations and Eloquent ORM.
* **Secure Authentication & Middleware:** Role-based access control protecting administrative routes from unauthorized users.

---

## 🛠️ Built With

* **Backend:** PHP, Laravel Framework
* **Frontend:** HTML5, CSS3, JavaScript, Blade Templating Engine
* **Database:** MySQL
* **Version Control:** Git & GitHub
